# Примерка взрослого ретро

Концепция выбрана пользователем для исследования: светлый каталог с глубокой
бордовой шапкой, взрослая роскошная эстетика винила и старых фотоаппаратов.
Оливковый в этой примерке исключён. Предыдущие строгие списки и мягкие
иллюстрированные варианты отклонены.

На десктопе сохраняются карточки с главным изображением, категорией, названием
и оценкой. На мобильном — строки с миниатюрой и краткой информацией.
Несколько фото загружаются в запись, одно выбирается главным; все доступны
в деталях. Основной экран не должен выглядеть как CRM.

Исследуем три композиции в одном визуальном мире: светлая галерея,
компактная коллекция и более выразительная бордовая верхняя область.
Макеты демонстрационные, ещё не одобрены для реализации. Текущий интерфейс
и DESIGN.md не изменяются до выбора.

Это новый выбор пользователя после первоначального исследования
seed:387e360a5763d48c; прежняя трактовка строгого списка больше не актуальна.

и рабочий интерфейс ещё не заменены.
