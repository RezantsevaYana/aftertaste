# Vue: теория и вопросы для собеседований

## Props и defineProps в script setup

Props — входные данные, которые родительский компонент передаёт дочернему.

```vue
<!-- В родительском компоненте -->
<EntryImage :type="entry.type" />
```

```ts
// В EntryImage.vue, внутри <script setup lang="ts">
const props = defineProps<{ type: ContentType }>()
```

- `defineProps` — макрос компилятора Vue для объявления props в `script setup`.
  Импортировать его из Vue не нужно.
- `<{ type: ContentType }>` — аргумент типа TypeScript: описание объекта
  входных свойств. Поле `type` обязательно и имеет тип `ContentType`.
- `()` — вызов без аргументов-значений: описание передано на уровне типов.
- `const props =` — сохраняет доступ к объекту входных свойств.
  В скрипте значение читаем через `props.type`.

Здесь `type` — выбранное имя свойства, а не ключевое слово объявления
псевдонима типа. `ContentType` — тип допустимых категорий из модели записи.
Объявление не выбирает категорию и не задаёт значение по умолчанию:
значение приходит от родителя.

```ts
const image = computed(() => images[props.type])
```

Props реактивны: когда родитель передаёт другую категорию, вычисление,
которое читает `props.type`, обновляется. Дочерний компонент не должен
присваивать новое значение самому prop. Для запроса изменения у родителя
используют событие, объявленное через `defineEmits`.

### Вопросы и ответы

**Что такое props?**  
Входной интерфейс компонента. Данные передаются от родителя к ребёнку,
а изменения принадлежат их владельцу в родительском компоненте.

**Что означает двоеточие в :type="entry.type"?**  
Это сокращение `v-bind:type`: Vue вычисляет выражение `entry.type` и передаёт
его значение. Без двоеточия `type="entry.type"` передаст буквальную строку.

**Обязательно ли присваивать результат defineProps переменной?**  
Нет. `defineProps<{ type: ContentType }>()` достаточно, если свойства нужны
только в шаблоне: там можно обращаться к `type` напрямую. Объект `props`
удобен для чтения свойств в скрипте.

**Зачем фигурные скобки внутри угловых?**  
Угловые скобки передают аргумент типа, фигурные описывают объект с полями.
Это не создание объекта JavaScript. Вместо встроенного описания можно
объявить `interface Props { type: ContentType }` и вызвать `defineProps<Props>()`.

**Как сделать prop необязательным?**  
Добавить `?`: `defineProps<{ type?: ContentType }>()`. Тогда при чтении
нужно учитывать отсутствие значения или задать значение по умолчанию,
например через `withDefaults(defineProps<Props>(), { type: 'book' })`.

**Почему props обновляются, хотя переменная объявлена через const?**  
`const` запрещает переприсвоить переменную `props`, но не делает объект
неизменяемым. Реактивное обновление входных свойств обеспечивает Vue.
Запрет на их изменение дочерним компонентом связан с правилами props,
а не с `const`.

**Защищены ли вложенные объекты в props от изменений?**  
Props доступны только для чтения на верхнем уровне. Вложенный объект
технически можно изменить по общей ссылке, но это может незаметно изменить
состояние родителя. Обычно вместо этого ребёнок отправляет событие.

**Проверяет ли defineProps точное соответствие ContentType во время выполнения?**  
TypeScript проверяет типы при разработке. Компилятор Vue может сгенерировать
базовые runtime-проверки props, но строковое объединение не становится
полной проверкой допустимых значений. Внешние данные требуют отдельной валидации.

## События компонента: defineEmits

```ts
const emit = defineEmits<{ open: [entry: Entry]; add: [] }>()
```

`defineEmits` — макрос Vue для объявления событий в `script setup`.
Импортировать его не нужно. Результат — функция `emit`, которой компонент
сообщает родителю о событии. Аргумент типа описывает имена событий и кортежи
их аргументов:

- `open: [entry: Entry]` — один аргумент типа `Entry`.
- `add: []` — событие без аргументов.

```ts
emit('open', entry)
emit('add')
```

Родитель подписывается на события:

```vue
<EntryList @open="selectedEntry = $event" @add="addEntry" />
```

`$event` здесь — переданная запись. Сам `emit` не открывает окно и не создаёт
запись: действия выполняет обработчик родителя.

### Вопросы и ответы

**Что означают квадратные скобки в open: [entry: Entry]?**  
Это тип кортежа: он описывает число, порядок и типы аргументов события.
`entry` — подпись элемента для читаемости и подсказок, а не создаваемая
переменная. Передавать массив не нужно: правильно `emit('open', entry)`,
а не `emit('open', [entry])`. `[]` означает отсутствие аргументов.

**Чем defineProps отличается от defineEmits?**  
Первый объявляет входные данные от родителя, второй — события, которыми
ребёнок уведомляет родителя.

**Как передать несколько аргументов?**  
`change: [id: string, rating: number]` позволяет вызвать
`emit('change', 'entry-123', 9)`. Обработчик родителя может принять оба
аргумента. `$event` в выражении шаблона обозначает первый аргумент.

**Что проверяет TypeScript?**  
Имя события и соответствующие аргументы. Для примера выше `emit('open')`,
`emit('add', entry)` и неизвестное имя события вызовут ошибки типов.
Это не runtime-валидация передаваемых данных.

**Всплывают ли события компонентов?**  
Нет, автоматически через дерево компонентов они не распространяются.
Промежуточный компонент при необходимости явно передаёт событие дальше.
