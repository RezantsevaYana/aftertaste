# Учебные конспекты

Теория по технологиям, которые разбираем при разработке Aftertaste:
краткие объяснения, примеры и вопросы для собеседований с ответами.
Документация самого приложения находится в [docs](../docs/).

## Темы

- [Vue](vue.md) — props, defineProps, передача данных от родителя к ребёнку.

- [TypeScript](typescript.md) — интерфейсы, extends, структурная типизация,
  получение типов из значений, typeof, as const.

## Как ведём конспекты

- Каждой теме или технологии — отдельный Markdown-файл с именем в kebab-case.
  Например, `vue.md`, `http.md`, `nestjs.md`, `postgresql.md`.
- Создаём файлы по мере появления материала, без пустых заготовок.
- Внутри темы: краткая теория, небольшой пример, вопросы и ответы.
- Повторные вопросы дополняют существующий раздел, а не создают дубликаты.
- Связанные темы соединяем ссылками; новый файл добавляем в оглавление выше.
- Примеры из Aftertaste можно упрощать, явно отмечая это. Конспект не является
  стенограммой диалога или описанием текущей реализации проекта.
